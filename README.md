# LiveStickies

> **Note:** This repository hosts official documentation, release notes, and public issue tracking for the Microsoft Store release of **LiveStickies**. Source code is maintained in a private repository.

**LiveStickies** is a lightweight, native sticky notes app for Windows designed to stay fast, clean, and out of your way.

## Key Features

* **Quick Pastel Notes:** Jot down and organize notes with a simple color palette.
* **Native Windows Look:** Supports system, light, and dark themes and follows your Windows accent color.

## Download

Available on the [Microsoft Store](https://apps.microsoft.com/detail/9NBLGGH4WM0Q).
